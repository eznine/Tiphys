## 2. 参数口径（可解释，不假装默认即科学）

| 参数 | 取值 | 语义与依据 |
|---|---|---|
| 洼地处理 | `wasm_fill_depressions`（优先填洼） | Whitebox 填洼优先模式；未做 Breaching 对比（NOT_TESTED） |
| 流向算法 | **D8 单向**（`wasm_d8_pointer`） | 未提供 MFD；D8 在平原区易平行流（已知局限，报告在案） |
| 汇流单位 | **上游像元个数**（`wasm_d8_flow_accum` 原生输出） | 阈值按像元数解释；换算面积 = 像元数 × 像元面积 |
| 河网阈值 | 用户可调，默认 50 像元；敏感性见 §3 | 科学敏感参数，任务卡表单里明示"阈值越大河网越稀疏" |
| 参数名 | `d8_pntr`/`flow_accumulation` 等按 WASM manifest 原名 | 阶段 4 发现模型猜参数名会错；提示词已改为"参数名以上面写的为准" |

## 3. 实测结果（2026-10-24，Node 24 / Chrome WASM 1.7.1）

| DEM | 阈值 | 河网面数（连通域） | 河网总面积 deg² | 范围内 |
|---|---|---|---|---|
| dem_hills 120×100 | 20 / 50 / 100 / 200 | 1 / 58 / 59 / 1 | 1.14e-3 → 9.82e-5 → 5.98e-6 → 1.90e-7 | 全部 ✓ |
| dem_large 600×500 | 20 / 50 / 100 / 200 | 1 / 2035 / 2420 / 2 | 2.85e-2 → 1.41e-3 → 2.32e-4 → 1.90e-7 | 全部 ✓ |

**结构验收**（每格）：completed + 每步验收通过（填洼保持 DEM 网格、汇流保持网格、河网面非空且为多边形）+ 河网范围落在 DEM 范围内（独立读回复核，0.01° 容差）。8/8 通过；auditRuns 0 违规。

**敏感性不变量**：阈值↑ ⇒ 河网总面积（∝ 河网像元数）不增——两个 DEM 全部通过。

**方法学发现（第一轮实测的产出）**：河网**面要素数不能当敏感性指标**。它统计的是连通域个数：低阈值时整网连成 1 片，中阈值支流断裂碎片最多，高阈值只剩主干又归 1——第一轮用面数做不变量"全违反"，换总面积后全过。这个坑与"屏幕上有蓝线就当正确"是同一类错误，写进方法卡与本文档。

## 4. 验收清单（每次运行自动执行）

1. `fill` 输出网格 = 输入 DEM 网格（raster_dims，对照输入图层）。
2. `acc` 输出网格 = `fill` 网格（raster_dims，对照上一步）。
3. 河网矢量非空（feature_count ≥ 1）且为多边形。
4. 河网范围 ⊆ DEM 范围（独立几何读回）。
5. 全链审计：PlanRun 逐步 sha256、验收明细、错误分类；`auditRuns` 通过。
6. 交付：阈值 50 结果导出 GeoJSON，字节与 sha256 记录在 json。

## 5. NOT_TESTED（明确未测）

- **真实小流域**：本轮只用合成 DEM（正弦山丘 120×100、600×500）；路线图要求"合成 + 至少 2 个真实小流域"，真实 SRTM/ALOS 样例尚未接入（需要数据源与下载管线）。
- **MFD 对照**：目录无 MFD 汇流工具，D8 平原平行流风险未量化。
- **流域划分与出口 snap**：`wasm_basins`/`wasm_watershed` 未纳入本纵向（阶段 4 M11 显示模型找 basins 参数困难，属后续工作）。
- **Strahler 分级与河流统计表**：`wasm_strahler_stream_order` 存在但未进链。
- **阈值单位换算**（像元 → km²）未在 UI 呈现换算结果。
