# TIPHYS Mobile V2.2 — 现状审查、设计规范与实施方案

> 分支 `feat/mobile-ui-v22` · 独立 worktree（工作区内 `tiphys-mobile-v22`）· 基于 `main@a48c9c3`
> 已快进合并到 `main@e159512`；v2.2.1 按用户参考图完成品牌与底部操作区精修。
> 桌面布局不做视觉改动；所有移动端规则限定在 `.app-shell.mobile` 作用域内。

## 1. 现状审查（P0）

### 1.1 架构

| 层 | 现状 | 移动端可复用性 |
|---|---|---|
| 前端 | React 19 + TypeScript + Vite，单页 `App.tsx`（约 530 行）持有全部工作区状态 | 直接复用；只替换移动分支渲染 |
| 地图 | `MapCanvas.tsx`，MapLibre GL，globe/mercator、多底图、AOI 矩形绘制、点选要素、要素弹卡、PNG 导出 | 全部复用；新增移动控件与视图回调 |
| 图层 | `agent.state.layers` + `dataLayers.ts`，显隐/样式/排序/重命名/删除都走真实引擎工具 | 直接复用真实操作 |
| Agent | `useAgent`（SSE），时间线含 msg/tool/job/approval/notice；审批、取消、工具结果合并 | 直接复用 |
| 工具 | `ToolPanel`：引擎目录（1000+）、分类、搜索、按 schema 生成表单、真实 job、轮询、结果明细 | 复用执行与表单；新增移动浏览层与任务桥 |
| 任务卡 | `TaskCards`：真实 `run_plan`，执行前预算说明，执行后验收断言 | 复用；新增任务桥，把 run 记录进任务中心 |
| 持久化 | `workspace.ts` 快照（图层/选择/AOI）；`browser/storage.ts` IndexedDB 记录；计划运行 `plan-run:*` | 复用 IndexedDB，新增 `task:*`、`project:*` |
| 移动现状 | `mobile.css`（272 行）+ `BottomSheet` + `MobileComposer`，底部输入栏 + 聊天手柄 + 全功能抽屉 | 保留交互经验；本轮重构为四入口 + 悬浮工作台 |

### 1.2 关键发现与约束

1. **任务状态目前分散在三处**：Agent 的 `job`/`approval` 时间线、`ToolPanel` 组件内部 job、`TaskCards` 组件内部 run 结果。三者互不相识，无法满足“统一任务中心”与“同一任务 ID”要求。本轮新增客户端任务账本，把三路真实事件汇入同一记录，不伪造状态。
2. **工具轮询随组件卸载而停止**。关掉工具面板后长任务仍会跑，但结果不再合并进地图。本轮新增后台任务轮询器（浏览器页存活期间），并在页面重载后把无法恢复的浏览器任务标为“已中断”，不假装成功。
3. **没有工程实体**。现有只有一个全局工作区。本轮引入“数据保险库 + 工程视图”的诚实模型：数据仍保存在本机同一存储中，工程记录图层子集、顺序、显隐、AOI、地图视图与任务归属；切换工程是真实地应用这些状态，不复制、不删除数据。
4. **地图实例不能随导航重建**。四入口切换时地图保持挂载，只改变覆盖层；避免重复创建 WebGL 上下文与丢失相机状态。
5. **手机默认 2D**。3D 地球保留一键切换；这是性能取舍（移动端同时跑 WASM、图层渲染与玻璃合成），不是删功能。
6. **桌面不受影响**。桌面渲染分支、`tokens.css`、`app.css` 不改；新样式全部在 `.app-shell.mobile` 下。

### 1.3 修改范围

新增 `src/mobile/*` 页面与组件、`src/lib/mobile/*` 任务/工程账本、`src/styles/mobile.css` 重写（移动作用域）。改动 `App.tsx`（移动分支）、`MapCanvas.tsx`（移动控件与视图 API）、`ToolPanel.tsx`/`TaskCards.tsx`/`ChatTimeline.tsx`（可选任务回调，默认不改变桌面行为）。引擎、Agent、共享契约与后端接口不动。

### 1.4 风险

| 风险 | 处理 |
|---|---|
| 抽屉拖动与地图手势冲突 | 仅把手/标题区发起拖动，内容区独立滚动；`touch-action: none` 只作用于把手 |
| 玻璃在深色卫星底图上不可读 | 导航用玻璃、内容用高不透明实体；关键文字加 1px 内描边与足够对比 |
| 大量 `backdrop-filter` 掉帧 | 模糊只用于顶部胶囊、Dock、输入台、抽屉顶部；低性能设备自动降级为实体表面 |
| 工程切换与 Agent 上下文不一致 | 工程切换只改变可见性与视图；Agent 仍能看到数据保险库全部图层，报告中明确标注 |
| 任务账本与真实执行漂移 | 所有状态只由真实事件推进；无真实进度的任务只显示步骤，不显示百分比；重载时无法恢复的任务标“已中断” |

## 2. 最终 UI/UX 方案

### 2.1 信息架构

四个底部一级入口固定为 **对话｜地图｜任务｜工程**。图层与工具箱不是一级入口：它们从地图右上角进入。地图为默认入口，并在切换页面时保持挂载。

- **地图**：全屏真实地图；顶部左侧品牌/工程胶囊，右侧图层与工具玻璃按钮；右侧竖排地图控件（2D/3D、底图、定位、全图、AOI、测量）；底部悬浮 AI 输入胶囊 + 四入口 Dock。
- **对话**：会话时间线（含任务卡、计划、审批、任务摘要），上下文引用条（工程/图层/选中要素/AOI，可逐个移除），输入台。
- **任务**：统一任务账本。概览（运行中/待确认/失败/今日完成）、状态与工程筛选、搜索、列表、详情（输入、参数、步骤、日志、错误、成果、验证、操作）。
- **工程**：当前工程、创建/切换/搜索、四个页签（概览/数据集/成果/历史）、真实持久化。

### 2.2 材质与配色（浅蓝）

用户选择“浅蓝”，因此不采用规格中的深海军蓝主色；保留其冷白底与深墨蓝文字。移动端专属令牌（桌面 `tokens.css` 不动，后续可平移到其他端）：

| Token | 值 | 用途 |
|---|---|---|
| `--m-accent` | `#4C85D9` | 主操作、选中、发送 |
| `--m-accent-strong` | `#356CB8` | 按下态、深色文字强调 |
| `--m-accent-soft` | `#E9F1FC` | 选中底、浅色徽标 |
| `--m-bg` | `#F7F9FC` | 页面底 |
| `--m-ink` | `#23364D` | 主文字 |
| `--m-ink-2` | `#6E8099` | 次要文字 |
| `--m-surface` | `#FFFFFF` | 专业内容实体表面 |
| `--m-glass` | `rgba(255,255,255,.72)` | 导航玻璃 |
| 成功/警告/危险 | `#2F9E86` / `#D8912F` / `#D25B5B` | 状态，始终配图标与文字 |

深色主题给出对应色阶（`#0D1624` 底、`rgba(19,31,48,.72)` 玻璃、`#6FA5F0` 强调），保证卫星影像上的对比度。

材质规则：轻量导航（顶部胶囊、抽屉头）用玻璃；Dock、输入台、图层行、工具表单、任务详情、工程文件用实体表面。禁止整屏透明玻璃。

### 2.3 形状、层次、动效

主卡片 22–24px，Dock 28px，输入胶囊 999px，表单 14px，抽屉顶部 26px。阴影为低对比双层柔影，不使用霓虹描边。动效只做 transform/opacity：抽屉吸附 260ms、页面进入 220ms、Dock 选中 180ms；遵循 `prefers-reduced-motion`。低性能设备（`hardwareConcurrency ≤ 4`）关闭模糊与位移动画。

### 2.4 关键组件规范

- **MobileDock**：4 项，图标 + 文字，选中态只用强调色（图标填充与文字）并加粗，不铺胶囊底；任务运行或待审批时显示计数徽标（数字，不只靠颜色）。
- **MobileSheet**：真实三档高度（紧凑 28dvh / 半屏 55dvh / 扩展 92dvh），把手拖动实时跟手，松手吸附最近档；支持遮罩点击关闭、Esc、焦点回归。
- **图层抽屉**：紧凑档显示概览与当前图层；半屏显示列表；扩展显示详情。行内显隐、符号、类型/数量、排序把手；上下文操作按图层类型裁剪（矢量才有属性表/标注，栅格才有拉伸）。
- **工具箱**：搜索、分类、最近使用、收藏；工具页采用实体表单，必填校验、单位、字段下拉、图层下拉；提交后进入统一任务账本。
- **任务卡**：执行前说明引擎与预算；执行后展示验收断言；状态卡与任务中心使用同一 ID。
- **工程页**：工程卡显示图层/成果/任务计数；切换时真实应用图层顺序、显隐、AOI 与地图视图。

### 2.5 状态架构

| 领域 | 来源 | 移动端表现 |
|---|---|---|
| 地图 | `MapCanvas` + `mapView` | 保持挂载；工程可保存/恢复中心、缩放、2D/3D、底图 |
| 图层 | `agent.state.layers` | 抽屉、工程数据集、任务成果同源 |
| 对话 | `useAgent` SSE | 时间线；任务摘要只显示简短状态并链接任务详情 |
| 任务 | 新增 `taskStore`：Agent job/approval、手动工具 job、计划 run | 统一 ID、状态机、步骤、日志、验证、操作 |
| 工程 | 新增 `projectStore` | 当前工程、图层子集/顺序/显隐、视图、AOI、任务归属 |

任务状态机：`draft → pending_approval → queued → running → validating → succeeded`，旁支 `waiting / failed / cancelled / interrupted / resumable`。只有引擎给出真实进度才显示百分比；否则显示“步骤 n/m”。

### 2.6 响应式

手机竖屏为默认形态；横屏（`max-height: 520px`）把图层/工具抽屉变为右侧面板，Dock 变窄竖向排列；≥ 861px 回到桌面布局。安全区全部使用 `env(safe-area-inset-*)` 与 `dvh`，不依赖固定 `100vh`。

### 2.7 品牌与底部操作区（v2.2.1）

- **资产**：`public/brand/logo-mark.svg`（完整标志）、`logo-wordmark.svg` / `logo-wordmark-white.svg`、`logo-icon.svg`（透明方形）、`logo-badge.svg`（深色圆角徽章，favicon 与浅色胶囊内使用）。源图 `docs/brand/tiphys-logo-source.png`，字标平滑轮廓 `docs/brand/wordmark-traced.svg`，生成脚本 `scripts/brand/build_logo.py`。
- **放置**：桌面顶栏（徽章 + 字标）、桌面 Agent 面板标题、移动地图左上角工程胶囊（徽章 + 字标 + 工程名）；favicon 与 Tauri 应用图标（`src-tauri/icons`）同样使用徽章。字标用 CSS mask + `currentColor` 渲染，明暗主题自动取色，不重复导出两套位图。
- **底部操作区**：按参考图改为实体表面（浅色白面、深色 `--m-surface`）。输入台高 56px、圆角 28px，加号为中性浅灰圆钮；Dock 高 64px、圆角 28px，选中态只改强调色，不铺胶囊底。玻璃仅保留在顶部胶囊与抽屉头，减少合成开销。

### 2.8 v2.3 真机反馈精修

用户在真机上复核 v2.2.1 后指出七处断层，本轮逐条修复，仍限定在 `.app-shell.mobile`：

1. **底部只有一张卡**。新增 `MobileBottomCard`：状态行、AI 输入框、四入口 Dock 共用一个实体卡片（地图页与对话页复用），去掉输入框和 Dock 之间的大片空白与重复聊天按钮。
2. **输入时只留输入框**。卡片内 `data-input-focused` 折叠状态行与 Dock；卡片外的任何文本/下拉/多行输入聚焦时，`.m-shell[data-form-focused]` 同时隐藏浮动 Dock（工程页、抽屉表单等），失焦后恢复。
3. **图例与坐标贴边**。两者改为固定在底部卡片上方（图例 +40px、坐标读数 +6px），不再悬浮在地图中部；横屏隐藏图例，只保留下方横向卡片。
4. **符号化抽屉化**。`LayerProperties` 以 55%/92% 两档 `MobileSheet` 打开，地图仍可见；关闭抽屉回到图层列表，不再出现“看不到地图也看不到图层”的空白页。
5. **工具箱全程抽屉**。工具目录与具体工具表单共用同一个可拖动抽屉（55%/93%），表单头带返回箭头；目录 hydrate 时不再清空正在填写的工具（去掉 `ToolPanel` 载入完成后的 `setToolName("")`）。
6. **属性表铺满屏幕**。移动端 `.m-fullscreen-panel .attribute-table` 强制 `height: 100%`，属性行恢复可见；从图层抽屉打开属性表时先关闭抽屉，避免遮罩压住全屏面板。
7. **抽屉内容可滚**。`MobileSheet` 将正文最大高度限制在当前可见区域内，半屏抽屉里的长表单可以滚动到“运行”，不用先拖高；同时避免面板自动聚焦抢走表单字段的焦点。

## 3. 实施顺序

1. **P0** 本文档。
2. **P1** 令牌、四入口骨架、地图常驻、悬浮输入台与 Dock。
3. **P2** 地图控件（2D/3D、底图、定位、全图、AOI、测量）与可拖动图层抽屉。
4. **P3** 工具箱浏览层 + 真实工具表单 + 任务账本接线。
5. **P4** 对话页上下文引用、任务中心/详情、审批与取消、后台轮询、验证。
6. **P5** 工程页、工程切换、数据集/成果/历史、持久化恢复。
7. **P6** 视觉精修、低性能降级、横屏、构建与真实交互验证、截图与报告。
