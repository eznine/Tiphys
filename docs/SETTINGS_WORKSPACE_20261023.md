# 2026-10-23 API 设置与 GIS 工作台续作

## 问题与改动

用户提供 ArcGIS Pro 截图作为交互与布局参考，要求 Agent 仍是默认入口，同时具备熟悉的 GIS 常规操作。原桌面进程经 `/health` 核实为 `mock:mock-gis`；本机 Roaming 应用目录中的 13 个真实密钥仍存在。源代码及同环境下提取的旧打包配置加载器均能读取该文件，未取得旧进程首次启动读取失败的证据，不能断言是密钥丢失或某个路径错误。

已确认的设计问题是：缺少凭据就静默切换 Mock，配置仅在启动加载，界面没有查看、更正和应用配置的入口。本轮取消自动 Mock 回退：只有显式测试环境 `TIPHYS_LLM_PROVIDER=mock` 才启用模拟模型；正常未配置时返回 `unconfigured`，对话区显示设置入口。

- 设置：API 地址、模型、密钥池、真实连接测试、保存立即生效；留空保留全部现有密钥，已有密钥不返回前端。启动环境覆盖和运行中任务会明确阻止保存。配置原子写入应用数据目录 `agent.json`，重启读取。
- 外观：浅色、深色、跟随系统；标准与紧凑内容列表；界面保持简体中文。
- 运行参数：模型上下文窗口和工具输出上限；没有添加统一的模型思考时长限制。连接诊断请求单独设有 60 秒等待上限。
- 工作台：地图/分析/视图命令分组；内容搜索、选中图层、可折叠图例及当前标注字段；地图文档栏；真实鼠标经纬度、地图级别与坐标显示基准状态栏。
- Agent：默认对话、多行输入、Enter 发送/Shift+Enter 换行、添加数据、选中图层上下文和实际模型名称。工具箱作为并行入口；命令栏打开具体工具时带入选中图层。
- 修复审批卡与工具卡共用 React key 的冲突；历史模型设置事件不再覆盖当前健康检查中的实际模型。
