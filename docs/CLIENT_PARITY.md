核对日期：2026-10-25（初版 2026-10-24）。以本机 `F:\GeoAgentPro` 当前源码为依据，参考 `src/GeoAgentPro/Config.daml`、`Agent/ToolRegistry.cs` 和 `Chat/LogWindow.xaml(.cs)`。以下是源码入口对照，不把插件中出现一个按钮等同于该功能在客户端已经实现。

> **2026-10-25 更新：** 浏览器已支持 GeoTIFF 栅格显示/预览、唯一值与分级设色、定义查询、本页 CSV/真 XLSX、原生真质心与空几何过滤；Web/桌面均已交付。表中仍写“栅格/分级/定义查询未做”的行属于历史快照，以本注和当前 `MASTER_ROADMAP` 为准。

当前目录以运行时合并结果为准：浏览器和 Tauri 联合目录均包含 958 个 GeoLibre WASM schema，加上 34 个公共 MCP 工具、5 个扩展工具和原生 `centroid`、`drop_empty_geometries` 几何/清洗工具，去重后为 999 个；工具箱隐藏 4 个引擎控制项后显示 995 个。Python sidecar 自身仍只有 34 个 MCP 工具，WASM 与扩展走混合路由。

## 浏览器与 Tauri 路径

| 路径 | 纯浏览器 | Tauri 混合 |
|---|---|---|
| 空间引擎 | 页面内 GeoLibre WASM | `wasm_*` 在 WebView worker；其他工具走 Python MCP |
| 工具目录 | 40 个壳层工具，异步 hydrate 到 999 | Python 目录 + 同批 WASM/壳层工具，去重到 999 |
| Agent | 浏览器内 AI SDK 工具循环 | Node Agent sidecar + Python MCP；WASM 手动工具并行可用 |
| 文件导入 | 浏览器文件选择器 / 沙箱样例 | 原生文件选择器 + Python sidecar |
| 持久化 | IndexedDB | 桌面应用数据目录与项目 `.tiphys` |
| GEE | 状态/检索/导出壳层，演示可走本地假任务 | 同一 GEE 准备路径，Python 侧仍明确未验证真实会话 |

两端共享结果图层事件、AOI、选择集和地图渲染，但浏览器任务 ID 不会错误转发给 Python。

## 固定产品原则

- Agent 是默认入口：打开应用先看到对话，添加数据后直接描述目标，由 Agent 选择工具、处理参数、串联执行并显示结果。
- ArcGIS Pro 是常规 GIS 交互的主要参考：内容列表、右键菜单、地图下方属性表、符号化、标注、按工具集分类等保留熟悉的逻辑。
- 手动工具作为并行入口，使用与 Agent 相同的工具契约；不能要求用户先找工具箱才能完成分析。
- 通用能力直接使用维护中的开源库；客户端独立于 ArcGIS Pro，不将 ArcPy 或 Pro 宿主能力伪装成已经移植。
- 尚未移植的能力必须明确显示在对照与后续计划中，不能用“完整 GIS”或“插件全量对齐”描述当前版本。

## 后续顺序（2026-10-25）

1. **证据硬化**：30 任务 ≥3 次方差、真机、桌面 GUI 启动/关闭；不改变产品行为。
2. **阶段 5A 真实小流域**：下载 → CRS/网格/NoData 体检 → 入库 → 河网/流域纵向，至少 2 个真实 DEM。
3. **阶段 5B 路网距离**：接入可复现的路网 provider，把服务圈从欧式扩展到路网。
4. **阶段 6 数据与交付**：GEE 真实链路、STAC/COG/OSM、打印布局；A1 剩余全表 CSV/XLSX、字段编辑、撤销、大图层性能。
5. **Bangkok 大矢量**：仅当出现高频 2 万级矢量任务再投入；当前保留预算守卫与桌面/分块降级。

生态模型、Play Store、多 Agent、3D/LiDAR 仍延后。以上顺序以 [MASTER_ROADMAP](MASTER_ROADMAP.md) 的「2026-10-25 进度快照与下一阶段决策」为准。
